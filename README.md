# GetSpread
# 海外FXリアルタイムスプレッド取得ツール

## 概要

海外FX業者のスプレッドを**24時間自動で取得・表示するツールです。  
VPS上のLinux環境で常時稼働し、取得したスプレッドを**Web上にリアルタイム表示**する仕組みを構築しています。

自身がFXジャンルのWebライターとして活動する中で、「スプレッド情報を手入力している」「情報がすぐ古くなる」という点に非効率さを感じ、  それを解決するためにこのツールを個人開発しました。

---

## 技術

- 言語：Python
- フレームワーク：Flask
- データベース：SQLite
- Webフロント：HTML、BootSrap
- API：MetaTrader5
- インフラ：ConoHa VPS（Ubuntu）
- その他：Cronで定期実行、nginxでデプロイ

---

## 機能

- MT5から主要通貨ペアのスプレッドを一定間隔で取得し、SQLiteに保存
- 保存したスプレッドデータをWeb表示
- iframeで外部ブログ等に埋め込み可能
